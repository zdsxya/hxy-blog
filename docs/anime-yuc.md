# 季度新番与公开追番清单

`src/config.ts` 中的 `anime.mode: "yuc"` 使用長門有C的 [yuc.wiki](https://yuc.wiki/) 季度新番表。

## 选择追番

1. 运行 `pnpm dev`，在本机打开 `http://localhost:4321/anime/`（端口以终端输出为准）。
2. 在“季度新番”选择季度，搜索番名、制作公司或题材，点击“添加追番”。
3. 在“我的追番”管理“在看 / 想看 / 看完”状态，也可以移除条目。每次操作会立即写入 `src/data/anime-watchlist.json`；刷新、重启、切换季度都不会丢失。
4. 将这个数据文件随网站代码一同提交、构建和部署，所有访客就能看到同一份清单。线上页面只读，不提供访客添加按钮。

这是静态站点的本地编辑流程，不是在线管理后台。编辑接口只在 `pnpm dev` 时启用，并且只接受本机、同源请求；`pnpm build` 和 `pnpm preview` 不提供写入接口。公开页面不依赖浏览器 localStorage。

## 同步新番

- 编辑页点击“同步新番”，或运行 `pnpm update-yuc`，同步北京时间所属季度及下一季度。
- `pnpm build` 会通过 `update-anime` 自动同步。下一季尚未发布或网络失败时保留已有缓存，终端会提示；没有任何有效缓存时构建明确报错。
- 需要其他季度时运行 `pnpm update-yuc --season 202604`，之后该季度会出现在下拉菜单中。
- 抓取结果存放在 `src/data/yuc-catalog.json`，请纳入版本管理，以便没有网络时也可以预览或构建。抓取只更新番目资料，不会替你新增或移除追番。
- 网络需要代理时，使用环境变量 `HTTPS_PROXY` 指定代理，脚本不绑定特定机器的代理地址。

条目 ID 基于季度和原文标题，不随页面排序变化。清单保留所选番目的资料快照，因此旧季度不在当前同步范围内也能正常展示。不虚构评分、集数或观看进度。

新番表资料来源为長門有C / yuc.wiki，页面保留来源链接和原站 BY-NC-SA 许可说明；封面沿用源站图片地址，加载失败时显示番名占位。

## 验证

运行 `node --test scripts/tests/yuc.test.mjs` 检查解析、季度计算、缓存保护和公开清单保存规则。
